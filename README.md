# 경주시 농어촌도로 지도

경주시 농어촌도로 및 시도 현황을 Kakao Map 기반으로 표시하는 정적 웹 지도입니다.

## 주요 데이터
- roads.geojson: 경주시 농어촌도로
- city_roads.geojson: 경주시 시도
- City Boundary.geojson: 경주시 경계
- Township Boundary.geojson: 읍면동 경계 원본
- township_overview.geojson: 읍면동 선택/개요 경계
- township_detail_lines.geojson: 읍면동 상세 경계선
- Ri Boundary.geojson: 경주시 리 경계만 추출

GitHub Pages 게시 시 main 브랜치의 /root 를 사용합니다.
